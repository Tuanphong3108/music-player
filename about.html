Audio Player là trình phát nhạc cục bộ chạy hoàn toàn trên trình duyệt (không cần cài đặt, không server) — mở nhạc bằng cách chọn file, kéo-thả, hoặc double-click mở trực tiếp khi cài như PWA. Ngoài phát nhạc cơ bản (Shuffle, Repeat, tua nhanh, phím tắt đầy đủ), điểm đặc biệt là bộ công cụ chỉnh sửa metadata trực tiếp lên file MP3 gốc: sửa Tên bài, Nghệ sĩ, Album, Genre, Composer, Lyric (embed + đồng bộ theo thời gian), cắt/xoay ảnh bìa — và ghi đè thẳng vào file thật trên ổ đĩa (không phải bản sao tạm) nhờ File System Access API.

Hỗ trợ hiển thị lyric đồng bộ ở màn hình chính, chế độ Picture-in-Picture và Full screen riêng biệt, giao diện Material Design 3 với nhiều theme màu tuỳ chỉnh (sáng/tối/hệ thống), cùng các tuỳ chọn tối ưu hiệu năng (giảm hiệu ứng chuyển động/mờ) cho máy cấu hình thấp. Tìm kiếm playlist thông minh (không dấu vẫn ra kết quả, tìm sâu cả Genre/Composer), có sẵn kênh gửi phản hồi/báo lỗi tích hợp ngay trong app.
